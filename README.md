# School-Zombies-Invading

# 生化 · 校园突围

3D第一人称学校生化丧尸射击游戏

一款基于 Three.js 的浏览器端第一人称生化生存射击游戏。雨后黄昏的校园被丧尸围困，你手持一把 AK-47，独自守住这片操场。

场景

内有多个地图
· 环形操场：标准椭圆跑道与球场，可绕圈跑动拉开距离
· 教学楼：东西两翼 + 中央楼体，内部四通八达，可推门进入躲避
· 东侧体育馆：纵深 55 米的封闭场馆，是打游击的好去处
· 蓝色主席台、绿荫树木、铁丝围栏：还原一座真实的校园

玩法

· 无尽波次：每波丧尸数量递增、速度与血量增强，难度逐波攀升
· 第一人称射击：鼠标锁定视角，左键或 F 开火，枪口火光、弹壳粒子、曳光弹道实时反馈
· 爆头一击必杀：命中头部直接击杀，躯干需多枪
· 走路与疾跑：Shift 疾跑消耗体力，体力耗尽需喘息回复
· 血量与换弹：30 发弹匣，R 键换弹；被咬掉血，波次间隔回血
· 室内躲避：教学楼与体育馆是安全屋，但丧尸会沿门洞涌入

手感细节

· AK-47 全枪由程序化几何建模：机匣、枪管、木质护木、弹匣、快慢机共 13 个可分解部件，材质与木纹均为程序生成
· 枪械后坐、走路摆动、换弹下压动画
· 湿地实时反射：地面水洼动态映射场景倒影
· 程序化音效：枪声、命中、丧尸低吼、撕咬，全部由 Web Audio 现场合成
· 一阵小雨：点击按钮即可召唤降雨，雨滴、雾气、天色同步变化
· 自适应画质：FPS 过低自动降分辨率与反射频率，可手动开关反射

操作

键位 功能
点击画面 锁定鼠标环视
W A S D 移动
Shift 疾跑
左键 / F 射击
R 换弹

触屏：左侧虚拟摇杆移动，右侧滑动环视，右下角 FIRE 开火，疾跑与换弹按钮独立可点。

技术

纯 WebGL 实时渲染，无外部模型与贴图资源——所有建筑、地形、丧尸、AK-47 模型与材质均在运行时程序化生成。支持移动端触控、指针锁定、动态降质，一个 HTML 文件即可运行。
