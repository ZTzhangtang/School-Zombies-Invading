# 🧟 生化 · 校园突围

> 一款基于 **Three.js / WebGL** 的校园僵尸生存射击游戏。  
> 在雨后校园中抵御无尽丧尸波次，探索教学楼、体育馆与操场，用 AK-47 守住每一道门。  
> 支持单人游玩，并包含 **P2P 联机系统**。

## 一句话简介

**丧尸围城，校园告急。**  
你是最后一批幸存者之一，必须利用校园地形、教室、楼梯与操场，在无尽波次中活下去。

## 基本信息

- **游戏名称**：生化 · 校园突围
- **英文名**：Zombie Campus Breakout
- **类型**：第一人称射击 / 生存 / 无尽波次 / 多人联机
- **引擎**：Three.js + WebGL
- **联机**：PeerJS / WebRTC DataChannel
- **平台**：现代浏览器（Chrome / Edge / Firefox）
- **操作**：键鼠 / 触屏
- **版本**：v1.0

## 核心玩法

- 丧尸从校园四周不断涌入，波次越高数量越多、速度越快。
- 击杀丧尸获得分数，波次间可恢复生命。
- 可进入教学楼、体育馆、教室与内院，利用地形躲避和反击。
- 丧尸会追踪玩家，也会上楼追击。
- 支持爆头一击、弹药管理、换弹、疾跑体力与开镜瞄准。
- 卡顿自动降质，实时反射可手动开关。

## 操作方式

### 键鼠

- **点击画面**：锁定鼠标环视
- **W A S D**：走路
- **Shift**：疾跑，消耗体力
- **左键 / F**：射击
- **右键按住**：开镜瞄准，更稳更准
- **R**：换弹
- **1 / 2 / 3**：切换武器
- **Esc**：返回 / 退出锁定

### 触屏

- **左摇杆**：移动
- **滑动屏幕**：环视
- **右侧按钮**：开火 / 疾跑 / 换弹 / 瞄准

## 地图与场景

- **雨后 · 校园操场**  
  环形跑道与双庭院教学楼，地面水洼实时反射，教学楼与体育馆可进入躲避。

- **生化 · 校园突围（完整校园）**  
  整座校园开放：教学楼、体育馆、环形操场与两处内院，丧尸从四面八方涌入，高阶难度。

- **开发中地图**  
  夜幕 · 宿舍楼：手电筒照明，狭窄走廊，能见度极低。  
  废墟 · 城市街区：残垣断壁与废弃车辆构成的巷战地图。

## P2P 联机系统

- 房主创建房间，生成房间码。
- 好友输入房间码加入。
- 房主权威模拟僵尸，各端模拟自己的玩家。
- 20Hz 状态同步：玩家位置、角度、血量、武器、僵尸快照。
- 支持射击特效、命中、玩家离开、聊天等事件同步。
- 大厅 UI：玩家列表、开始游戏、退出房间。

## 技术亮点

- **纯 WebGL / Three.js 实时渲染**
- 建筑、地形、植被、AK-47、丧尸等大量资源程序化生成
- 雨后校园氛围：雨效、雾效、湿地实时反射
- AK-47 程序化模型：第一人称持枪、腰射 / 开镜切换
- Web Audio 合成枪声、命中、丧尸低吼、雨声
- 动态画质：根据 FPS 自动升降像素比、反射频率与阴影频率
- P2P 联机基于 PeerJS / WebRTC DataChannel

- 显示 FPS 开关

- `map1.html`：完整校园地图
- `map2.html`：雨后校园操场地图
- `p2p.js`：P2P 联机系统，大厅、房间、状态同步
- `model.js`：实体与联机逻辑模块

## 快速开始

1. 打开 `index.html`。
2. 点击 **开始游戏** 快速进入上次地图。
3. 或进入 **地图选择**，挑选地图后点击 **进入**。
4. 在设置中调整画质、灵敏度、音量、反射与 FPS 显示。
5. 进入游戏后，点击画面锁定鼠标，开始抵御丧尸。
